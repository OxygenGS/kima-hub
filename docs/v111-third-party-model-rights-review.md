## First-party UPF ONNX alternative — exact numerical proof, 19 October 2026

**A technically credible alternative to packaging independently converted models now exists.** MTG/UPF itself publishes ONNX versions of the same **11 MusiCNN models** on `essentia.upf.edu/models/`: one [feature extractor](https://essentia.upf.edu/models/feature-extractors/musicnn/) and the ten matching [classification heads](https://essentia.upf.edu/models/classification-heads/mood_happy/). The official page itself describes the availability of ONNX and also points to the conflicting model licensing statements.

- [Binary SHA256 inventory #39208036446](https://github.com/OxygenGS/kima-hub/actions/runs/39208036446): **11/11 official ONNX files retrieved, 0/11 byte-identical** to our repository-converted ONNX files. Distinct serialization does not establish different semantics. SHA256, sizes and exact official URLs are in a retained JSON artifact.
- [Independent CPU ONNX inference comparison #39208570035](https://github.com/OxygenGS/kima-hub/actions/runs/39208570035): **PASS** on deterministic synthetic MusiCNN mel spectrograms (`187 × 96`). The official backbone's *default first output* is `activations` (**50** tags), whereas the application uses the *named second output* `embeddings` (**200** values). Selecting `embeddings` explicitly produces **minimum embedding cosine similarity 1.0** between fork and official weights. **All ten** official classification heads then returned numerically matching outputs with maximum absolute deviation **1.430511474609375×10⁻⁶**, far below the application gate of 1×10⁻⁴. This comparison is synthetic, not a full native AIO real-music test.
- Consequently an *optional future change* to source and Docker image could use **the 11 unmodified UPF-published ONNX files** and select the official backbone's named `embeddings` output. This likely preserves classification behaviour, but still needs architecture-specific CI, real-music validation, SHA256-pinned official downloads and a new published candidate if legally permitted.
- **Crucial limitation:** UPF making ONNX files downloadable **does not by itself confer redistribution rights** to the OxygenGS fork. The ND-vs-SA and noncommercial conditions still need written clarification. Replacing converted with official ONNX files will only help if UPF authorizes third-party redistribution on terms we can follow. No such clearance is recorded.

**Action requested from rights holder:** written confirmation for the eleven **first-party ONNX artifacts**, alongside the separately converted ONNX graph files, including license edition, redistribution, commercial/noncommercial self-hosted use, required attribution, and whether binary-image distribution is covered. [Prepared updated inquiry](v111-upf-model-license-inquiry.md). **Nothing has been sent.**
